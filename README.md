# Re:ANIME for Aniyomi / Anikku

You do **not** need a custom APK.

Re:ANIME is already in the official Yūzōnō anime extension repo, including playback.

## Fastest install

1. Open **Aniyomi** or **Anikku** (not Mihon).
2. Settings → Browse → Extension repos → Add:

```
https://raw.githubusercontent.com/yuzono/anime-repo/repo/index.min.json
```

3. Browse → Extensions → search **Re:ANIME** → Install → Trust.

Guide: https://yuzono.github.io/docs/guides/getting-started

## Sideload APK from this repo

GitHub Actions builds the official `src/en/reanime` module from [yuzono/anime-extensions](https://github.com/yuzono/anime-extensions).
Releases: https://github.com/pixel404dot/reanime-aniyomi-extension/releases
